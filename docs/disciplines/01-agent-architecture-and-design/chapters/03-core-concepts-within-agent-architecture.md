# Chapter 3 — Core Concepts Within Agent Architecture

This chapter introduced important terms that will be developed further as the curriculum progresses.

## Concepts introduced

- **Agent architecture:** the organisation of the components and relationships that make an agent work.
- **Harness engineering:** the surrounding structure, controls and mechanisms used to make a model operate as part of a useful system.
- **Runtime:** the environment and operational mechanisms through which the agent executes.
- **Goal architecture:** how objectives are represented and organised.
- **State management:** how the system maintains and updates information about its current condition and progress.
- **Identity:** how an agent is distinguished within a system.
- **Configuration:** the settings and parameters that shape an agent's operation.
- **Lifecycle:** the stages through which an agent is created, initialised, operated, maintained and retired.
- **Boundaries:** limits on the agent's scope, authority, access and behaviour.
- **Capability architecture:** how the capabilities available to an agent are organised.

## Learning status

These concepts were introduced as a vocabulary and conceptual map. Their detailed engineering treatment belongs in the relevant chapters and disciplines; this record does not imply that every concept has already been fully studied.
