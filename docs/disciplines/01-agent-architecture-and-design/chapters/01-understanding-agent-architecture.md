# Chapter 1 — Understanding Agent Architecture

## Core idea

An AI agent is a system that uses an AI model to pursue an objective by observing information, making decisions, interacting with tools or an environment, and evaluating results.

The important distinction is that an agent is goal-directed. It is not defined only by its ability to produce a conversational response.

## Chat response versus goal-directed activity

A conversational system may answer a question and stop. A goal-directed agent may need to interpret an objective, determine the work required, take actions, observe the results and decide what to do next.

An agent can still communicate through a chat interface. The interface alone does not determine whether the underlying system is an agent.

## Conceptual activity pattern

1. Receive or identify an objective.
2. Observe relevant information.
3. Interpret the current situation.
4. Select a decision or action.
5. Interact with the environment when authorised.
6. Observe the result and evaluate progress.

This is an introductory conceptual pattern, not a complete implementation specification.

## Key distinction

An agent is better understood as a system organised around pursuing an objective than as an AI model by itself.
