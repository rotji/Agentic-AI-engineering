# Chapter 4 — Agent vs Chatbot vs Workflow vs Automation vs Autonomous System

## Definitions

- **Chatbot:** primarily conversation-oriented; it responds to user inputs.
- **Workflow:** a defined sequence of tasks or stages.
- **Automation:** performs actions according to predefined rules or triggers and may not require AI.
- **AI agent:** uses model-driven decisions and actions to pursue an objective, with some degree of autonomy.
- **Autonomous system:** a broader system capable of sustained independent operation. It may contain agents, workflows, automation, databases, sensors and other components.

## How the categories relate

These are not mutually exclusive categories.

- An agent can operate inside a predetermined workflow.
- A workflow can include automated steps and agent-directed steps.
- An autonomous system may contain multiple agents and conventional software components.
- A chatbot can serve as the interface to an agentic system.

## Related vocabulary introduced

- Agentic workflow
- Hybrid automation
- Autonomy levels
- Supervisory control
- Agentic system
- Closed-loop system

## Illustrative example

An agricultural intelligence system may combine automated data collection, agents that interpret and analyse information, workflows that route findings for verification, and an autonomous operating layer that coordinates recurring activity.

The example illustrates a hybrid autonomous system. It is not a decision to build a specific system.

## Key lesson

Do not classify a system only by whether it uses AI. Examine its objectives, decision-making, execution, autonomy and the way its components work together.
