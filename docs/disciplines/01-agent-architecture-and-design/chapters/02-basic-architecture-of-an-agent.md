# Chapter 2 — Basic Architecture of an Agent

## Conceptual components

The introductory agent architecture includes:

1. **Objective or goal:** the outcome the agent is intended to pursue.
2. **AI model:** supports interpretation, reasoning and decision-making.
3. **Context:** information relevant to the current task and situation.
4. **Memory:** information retained for use beyond the immediate interaction where required.
5. **Tools:** capabilities through which the agent can interact with external systems or perform operations.
6. **State:** information about the agent's current position, progress or operating condition.
7. **Execution environment:** the environment in which the agent runs and performs authorised work.
8. **Observation and feedback:** information about what happened after an action and whether progress was made.

## Important qualification

This is a conceptual map, not a mandatory blueprint. Different agent systems may combine components, distribute them across services or omit components that are unnecessary for their task.

## Why the components matter

An AI model alone does not define the complete agent system. Goals, context, state, tools, execution and feedback shape how the model participates in goal-directed activity.
